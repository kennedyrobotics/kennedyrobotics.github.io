Install

  1. Download and open KR-Fit-Planner-Setup-1.1.0.exe.
  2. Windows may say “Windows protected your PC”, because the program isn’t code-signed yet. Choose More info, then Run anyway.
  3. Choose to install for just you (no administrator rights needed) or for everyone on the PC.

The installer adds KR Fit Planner to the Start menu and sets up the folder C:\KR-Fit\imports, with a starter plan (a Push / Pull / Legs week and KR Fit’s built-in exercises), a few example foods and a smoothie, and a “Read me”. Uninstalling removes the program but leaves that folder and your files.

Use it with KR Fit

  1. In KR Fit on your iPhone, export what you’d like to work on:
    • Plan ▸ Export or import ▸ Export plan and templates
    • Nutrition ▸ Foods and smoothies ▸ Export foods and smoothies
    • Plan ▸ Export or import ▸ Export workout history (to look through)
  2. Easiest, with iCloud Drive: in KR Fit choose Save … to iCloud Drive (KR Fit 0.8, build 36 or later), and install iCloud for Windows on your PC. The file lands in iCloud Drive ▸ KR Fit, and KR Fit Planner offers to use that folder, so nothing needs copying either way. OneDrive works the same way with its own KR Fit folder.
    Otherwise, save the file anywhere your PC can reach (or email it to yourself) and copy it into C:\KR-Fit\imports. Each export is named with its date and time, so they can all stay there.
  3. Open KR Fit Planner. It opens your newest plan and foods files automatically (File ▸ Choose exports folder changes where it looks).
  4. Make your changes and Save. The Planner checks the file the same way KR Fit does, so nothing gets skipped.
  5. In KR Fit choose Import latest … from iCloud Drive (or Import, and pick the file). KR Fit shows what will change before anything does.

Plan files with the exercise list need KR Fit 0.7 or later; foods and smoothies need KR Fit 0.8 or later. Help ▸ KR Fit Planner Help (F1) explains each tab, and Help ▸ Theme switches between light and dark.

Privacy

KR Fit Planner works offline on your own files. It doesn’t have an account, doesn’t collect anything and doesn’t send anything anywhere. Your files stay on your PC, wherever you keep them.
